## 4. Enforcement Architecture

RBAC is enforced on three distinct levels to prevent both visual clutter and direct parameter manipulation:
1. **Template Rendering Gate:** Jinja2 blocks like `{% if caps.can_manage_branches %}` prevent unauthorized buttons from appearing in HTML.
2. **Route Authorization Decorator:** `@roles_required(...)` and `@permission_required(...)` immediately reject unauthorized HTTP requests with HTTP 403 Forbidden.
3. **Domain Service Ownership Check:** Services like [`ShipmentService.book_shipment()`](file:///C:/Users/hp/Desktop/SMART_COURIER/app/services/shipment_service.py) validate `actor_user_id` against the entity owner, ensuring API-level isolation.
